# Monday Dash

Dashboard semanal de pacing para las cuentas con goal de $100K o más. Es una sola página (`index.html`) que se abre en cualquier navegador y no necesita servidor.

## Cómo se ve en línea
Con GitHub Pages activado, la página queda en:

https://jacoboroiz-da.github.io/Monday-Dash/

(GitHub escribe el usuario en minúsculas en esa dirección.)

## Activar GitHub Pages (una sola vez)
1. Abre el repositorio, entra a Settings y luego a Pages.
2. En Source elige Deploy from a branch.
3. En Branch elige main y la carpeta / (root). Guarda.
4. Espera uno o dos minutos y abre la dirección de arriba.

## Actualizar cada lunes
1. Descarga el `index.html` nuevo que se genera cada semana.
2. En el repositorio, pulsa Add file y luego Upload files.
3. Arrastra el archivo con el mismo nombre (`index.html`). GitHub lo reemplaza.
4. Escribe un mensaje, por ejemplo "Corte 8/11", y pulsa Commit changes.
5. En uno o dos minutos la página muestra la versión nueva, con el mismo link.

## Importante
- Quien tenga el link de la página puede ver el dashboard y también leer los datos que trae el archivo. No lo compartas fuera del equipo.
- Con la cuenta gratuita de GitHub, Pages normalmente exige que el repositorio sea público. Si necesitas que sea privado, hace falta un plan de pago o una organización.
- No subas aquí los CSV de Power BI ni de Everflow, ni documentos internos.
- Cambiar la página requiere permiso de escritura en el repositorio. Quien solo abre el link no puede modificarla.
